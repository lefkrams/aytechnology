Frequently Asked Questions

What does website maintenance include?

Website maintenance can include supported software updates, backups, security checks, uptime monitoring, content changes and technical troubleshooting.

Can you host an existing website?

We can review an existing website, its technology and requirements to determine whether migration to a suitable hosting environment is practical.

Do you support WordPress websites?

Support may be available for WordPress and other suitable website platforms after reviewing the site and its current configuration.

How often should a website be updated?

The right schedule depends on the website platform, plugins, security releases and business needs. Critical security updates should generally be addressed promptly.

Can you help if our website is down?

Yes. AY Technology can investigate supported hosting, domain, configuration and website issues to help identify the cause and available recovery options.
